# eligibility-snapshot-slice
Eligibility Snapshot
## Academic Context

This project is an Independent Study substitution for HCI 594 at DePaul 
University's College of Computing and Digital Media (CDM). The Eligibility 
Snapshot UI is the design deliverable. The full UCD process — research, 
synthesis, prototyping, and two usability test rounds — is the academic 
deliverable.

**No AI development is in scope.** The prototype connects to an existing 
AI backend for demonstration purposes only. All research and design work 
is conducted by the student researcher.
