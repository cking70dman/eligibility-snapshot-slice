Pre-Test Findings

Four issues identified through heuristic review prior to formal participant testing. Logged as UF-PRE series.

ID Screen Theme Severity Evidence Recommendation
UF-PRE-001 /intake Consent gate bypassable via direct URL 3 — Major Direct navigation to /intake skips the consent checkbox on the landing page Add server-side consent gate or redirect unauthenticated /intake requests to landing page
UF-PRE-002 /intake result Result renders below the fold 2 — Moderate No auto-scroll or scroll indicator after Q6 submit — result panel renders outside viewport Add smooth scroll-to-result on submit, or render result on a dedicated screen with clear visual break
UF-PRE-003 /intake URL static throughout flow 1 — Minor All steps remain at /intake — results are not bookmarkable or shareable via URL Implement hash routing or route-per-question for result shareability
UF-PRE-004 /intake result Progress bar reads 100% on result render 1 — Minor Result state is not Q7 — the label is ambiguous and may confuse users about completion state Hide progress bar on result render, or replace with a "Complete" label / checkmark state
